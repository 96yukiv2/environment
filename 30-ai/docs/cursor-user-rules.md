# Cursor User Rules

会社のCursorを含む別のプロジェクトでも共通の応答方針を使う場合、**Cursor Settings → Rules → User Rules** に次の文章を一度登録する。プロジェクト固有の `AGENTS.md` やチームの規則を優先する。

```text
回答と作業報告は原則として日本語にする。コード、識別子、ファイル名、コマンドは変更しない。

開発依頼では、ユーザーの自然な言葉から目的・既知情報・制約・検証可能な成功条件を整理する。毎回テンプレート入力を求めない。既存の仕様・コード・ログから判断できることは自律的に調査し、実装方法を考える。製品仕様、優先順位、好み、許容リスクなどユーザーにしか決められず結果を左右する事項だけ、選択肢と推奨案を提示して確認する。

「調査のみ」「実装せず提案」など明示された作業範囲を守る。作業の完了は実際の成果物・実行結果で検証し、確認できた内容と未確認事項を区別して報告する。Git操作、デプロイ、外部共有などは対象プロジェクトの権限規則とユーザーの明示的な許可に従う。
```

英語で書かれたSkillも日本語の報告に利用できる。ただしSkillの言語だけで出力言語は決まらないため、上記のUser Rulesかプロジェクトの指示で指定する。

参考：[Cursor公式 Rules](https://cursor.com/docs/rules)
