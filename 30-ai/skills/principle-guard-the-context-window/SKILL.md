# コンテキストウィンドウを守る（Guard the Context Window）

原典: https://github.com/cursor/plugins/blob/main/pstack/skills/principle-guard-the-context-window/SKILL.md

大量の出力や長いファイルによって主要な作業内容が埋もれないようにする。

## 適用

この原則が関連する作業を行うとき、原典の判断基準を優先し、変更内容と実際に確認した証拠を記録する。作業権限についてはルートのAGENTS.mdを優先する。
