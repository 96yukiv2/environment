# Blast radius

出典: https://github.com/cursor/plugins/blob/main/pstack/skills/blast-radius/SKILL.md

呼び出し元を列挙するだけで終えない。
差分に直接現れない破損を探す。

## 安全性の根拠

根拠の強さを区別する。

1. 推測しただけ。
2. 実際のコードを確認した。
3. 失敗条件に到達しないことを説明した。
4. テストやスクリプトを実行して確認した。
5. 動作中のアプリケーションで確認した。

## 手順

1. 差分、関連コード、PR、コミットを読む。
2. 安全性を左右する重要な前提を特定する。
3. 検索では見つからない依存関係も調べる。
4. リスクの発生条件、可能性、影響を評価する。
5. 実際のコードを使って重要な前提を検証する。
6. 大規模な変更では独立したレビューを組み合わせる。

## 報告

- 変更内容と振る舞いの変化
- 安全性を左右する前提と証明の程度
- 確認されたリスクと証拠
- 調査して問題がないと判断した事項
- 未検証事項とマージ前に必要な検証

検証できなかった内容を安全だと断定しない。
