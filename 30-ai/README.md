
# AI Skills

Lauren Tanによるpstackを参考にした日本語版Skills。

公式:
https://github.com/cursor/plugins/tree/main/pstack

## Skills

### よく使うSkills

| Skill | 用途 |
|---|---|
| how | コードの構造や動作を調査・説明する |
| why | 設計理由や変更の経緯を調査する |
| architect | 実装前に設計を比較・検討する |
| tdd | テストを通じて不具合を修正する |
| blast-radius | 変更の影響範囲と安全性を検証する |
| technical-writing | 技術文書を作成・改善する |

### 必要に応じて使うSkills

| Skill | 用途 |
|---|---|
| interrogate | 変更や設計を批判的に検証する |
| correct | 繰り返すミスを構造的に防止する |
| figure-it-out | 複雑な作業の進め方を設計する |
| in-your-own-words | 依頼の目的を整理する |
| unslop | 不自然で冗長な文章を修正する |

### 他のSkillsから参照するSkills

公式pstackの依存関係に基づいて配置する。

原則Skills、arena、swarm、no-comments、
show-me-your-workなどを対象とする。
